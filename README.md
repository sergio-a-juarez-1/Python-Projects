## 🛠️ Prerequisites & Dependencies

### Required Tools
* **Interpreter:** Python (v3.10+)
* **Environment Manager:** venv (Built-in) or Conda
* **Dependency Manager:** pip (v22.0+)

### Package Installation
On Ubuntu/Debian:
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv git
```

On macOS (using Homebrew):
```bash
brew install python
```
